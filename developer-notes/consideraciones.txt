# Consideraciones

## Generales

- Por cada Historia Médica pueden haber varias facturas (aunque casi siempre es solo una factura por historia).

- Las Historias en la vida real están asociadas es a facturas PROCESADAS (o sea, facturas buenas), Si la factura PROCESADA que tenían no sirve (por cualquier razón), hay que cambiar y poner la buena (aunque a nivel de sistema solo se edita los datos de la factura para poner los de la buena)

- Sorelys se basa es en las facturas, ella las anota TODAS, las PROCESADA, ANULADA y DEVOLUCION. Y anota toda la data de las PROCESADAS, de las ANULADAS y NOTAS DE CREDITO, solo anota el código de la Factura/Nota y el Código del control (Asi que todos los demás campos deben ser opcionales)

- Un paciente puede tener varias historias médicas (y una historia médica está asociada a un solo paciente). O sea, si el paciente llega, se le abre una historia médica, si se va, se cierra. Si vuelve se le tiene que abrir una nueva, y así sucesivamente

- Las notas de crédito sirven para pagar las facturas erradas (no son una nueva factura, son solo para saldar la deuda). Una vez hecha la nota de crédito, se hace la factura buena.
